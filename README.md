2. Run `npm run dev`

## LakiPay account totals

Copy `.env.example` to `.env.local` and set `LAKIPAY_API_KEY` to the
`PUBLIC_KEY:SECRET_KEY` value from LakiPay. Keep this variable server-only; do
not rename it with a `VITE_` prefix.

The integration uses Node.js 18+'s native `fetch`; it does not require Axios or
another HTTP client. Use `https://api.lakipay.co` for `LAKIPAY_BASE_URL`, unless
LakiPay has assigned a different API host to your account.

The dashboard calls `/api/lakipay-summary`, which keeps the API key out of the
browser and refreshes the displayed totals every 60 seconds. LakiPay's public
API reference does not document the response shape or public availability of
the merchant-wide aggregate routes. Set `LAKIPAY_BALANCES_PATH` and
`LAKIPAY_TRANSACTIONS_PATH` to the exact paths enabled for your account; a 404
means LakiPay has not enabled that path or the path is incorrect.
